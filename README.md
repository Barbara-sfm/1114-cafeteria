Menú Interactivo para Cafetería

Aplicación web interactiva diseñada para mejorar la experiencia de los clientes de una cafetería. Permite explorar el menú, seleccionar productos, administrar un carrito de compras y generar un ticket final para presentar en caja, reduciendo los tiempos de espera y evitando filas innecesarias.

Descripción

El proyecto consiste en una página web para la gestión de pedidos dentro de una cafetería. El cliente puede consultar los productos disponibles, agregarlos al carrito, modificar las cantidades o eliminar productos antes de confirmar su pedido.

Una vez finalizada la selección, el sistema calcula automáticamente el total y genera un ticket de compra que el cliente puede presentar en caja para realizar el pago o tambien ofrece un servicio de pago automatico ingresando la tarjeta de credito desde la app.

Funcionalidades

Visualización del menú y productos disponibles.

Consulta de precios y detalles de los productos.

Agregar productos al carrito de compras.

Aumentar o disminuir la cantidad de productos.

Eliminar productos del carrito.

Cálculo automático del subtotal y total.

Confirmación del pedido.

Generación de un ticket con el resumen de la compra.

Interfaz intuitiva y fácil de utilizar.

Reducción del tiempo de espera en caja.

Tecnologías utilizadas:

HTML5	Estructura de la página web
CSS3	Diseño y estilos de la interfaz
JavaScript	Interactividad, carrito y cálculo de pedidos
Python	Lógica del servidor y procesamiento de información
Flujo de uso

El cliente ingresa a la página web.

Explora las diferentes categorías y productos del menú.

Selecciona los productos que desea consumir.

Agrega los productos al carrito.

Revisa y modifica el pedido si es necesario.

El sistema calcula automáticamente el total.

El cliente confirma el pedido.

Se genera un ticket con el resumen de la compra.

El cliente presenta el ticket en caja y realiza el pago.

Objetivo del proyecto

El objetivo principal es desarrollar una solución digital que permita agilizar el proceso de pedidos en una cafetería, proporcionando una experiencia más cómoda para los clientes y facilitando la gestión de las órdenes.
